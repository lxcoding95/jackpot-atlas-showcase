**Trust boundary:** This public repository never hosts private lottery research, previously issued ticket fields, credentials, licensed third-party datasets or customer records. Fair lottery draws do not provide a demonstrable prediction advantage. Security incidents require human investigation; autonomous safeguards may report and stop, not silently relax protections.

## Maintenance policy

The canonical, version-controlled documents live in the repository links above; this wiki Home page is only a **navigation entry point**. Update the linked documents through protected pull requests, rather than keeping independent copies in the wiki. No separate wiki deploy key or broad-scoped automation token is necessary.

*Initial wiki setup:* paste this document into the GitHub wiki's first page named **Home**. Thereafter, linked content stays current with approved repository changes.
