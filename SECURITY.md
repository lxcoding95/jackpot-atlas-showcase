# Security policy

## Supported repository

The current `main` branch is the only supported version of this engineering showcase. It contains no lottery forecast service or customer application.

## Reporting a vulnerability

Please use GitHub's **Report a vulnerability** action in the repository Security tab when available. If private vulnerability reporting is unavailable, contact the maintainer through the GitHub profile before sharing technical details. Do not post credentials, personal data, or an exploit in a public issue.

## Response

Reports are triaged by the single maintainer. Automated checks do not replace human incident response. A confirmed issue may lead to a fix, a security advisory, or a documented no-fix decision.

## Scope and limits

The public showcase contains a small Python utility and GitHub workflow configuration. No uptime, response-time, or vulnerability-free guarantee is made.
